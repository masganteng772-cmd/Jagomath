Modern Android Engineering

Arsitektur Clean MVVM & CI/CD

Dibangun dengan Kotlin 2.4, Jetpack Compose Material 3, StateFlow, dan abstraksi MathRepository. Pengujian otomatis berjalan di GitHub Actions menggunakan JUnit 4, Robolectric, dan Android Lint.

  • UI: Jetpack Compose BOM, Edge-to-Edge Insets, Custom TTF Fonts
  • Cloud: Firebase Auth, Cloud Firestore, Credential Manager, Zero-Trust firestore.rules
  • CI/CD: Android CI, Automated Tag Releases, GitHub Pages, Dependabot
Quick Start — Local Build & Test 
# 1. Decode debug signing keystore
base64 --decode debug.keystore.base64 > debug.keystore

# 2. Run JUnit & Robolectric test suite
gradle :app:testDebugUnitTest

# 3. Run Android Lint & build Debug APK
gradle :app:lintDebug :app:assembleDebug
